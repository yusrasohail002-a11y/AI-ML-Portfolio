# E-commerce Abandoned Cart Recovery Automation

## Overview
An e-commerce automation project designed to manage cart states and schedule abandoned cart recovery workflows using n8n.

## Features
- Cart state management
- Automated workflow scheduling
- Abandoned cart recovery process
- Multi-step automation
- Workflow-based task coordination

## Tools & Technologies
- n8n
- Workflow Automation
- Scheduling
- E-commerce Automation

## Project Purpose
This project demonstrates how workflow automation can help e-commerce businesses manage abandoned carts and organize recovery processes.

## Project Type
Learning / Demo Project
