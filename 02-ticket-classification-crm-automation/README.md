# AI Ticket Classification & CRM Automation

## Overview
An AI-powered ticket classification and CRM automation workflow built using n8n and Google Gemini.

## Features
- Webhook-based ticket processing
- PII redaction
- Duplicate ticket detection
- AI-powered ticket classification
- CRM enrichment
- Google Sheets integration
- Slack notifications

## Tools & Technologies
- n8n
- Google Gemini
- Google Sheets
- Slack
- API Integrations
- JavaScript

## Project Purpose
This project demonstrates how AI and automation can simplify support ticket management and reduce manual work.

## Project Type
Learning / Demo Project
