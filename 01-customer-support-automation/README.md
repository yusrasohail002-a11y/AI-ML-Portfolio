
# AI-Powered Customer Support Automation

## Overview
An n8n workflow designed to process incoming customer support emails and classify requests using AI.

## Features
- Incoming email processing
- Data normalization
- Duplicate ticket detection
- AI-powered ticket classification
- Department-based ticket routing

## Technologies
- n8n
- Google Gemini
- Gmail
- Pinecone

## Purpose
Demonstrates how AI automation can help organize customer support requests and reduce repetitive manual tasks.

## Project Type
Learning and demonstration project.
